# Algora 数据结构与算法可视化

一个零依赖、可直接运行的中文数据结构与算法可视化学习网站。项目采用原创品牌和界面实现，不包含参考网站的源码、Logo、账户系统、文章正文或受保护素材。

## 当前版本

本版本重点补齐了“动画执行状态与真实代码联动”的核心学习体验：

- C/C++、Java、Python 三种语言标签页
- 每种语言展示对应算法的真实实现代码，而非只显示伪代码
- 每个动画帧绑定语义代码步骤，切换语言后仍定位到对应代码行
- 当前代码行使用边框高亮，并自动在代码子窗口内居中
- 动画画布内显示主要变量、数组下标指针箭头和逐步运行注释
- 可拖动进度条、上一步、下一步、播放、暂停、重置和速度调节
- 画布缩放、恢复比例和全屏显示

## 已包含的内容

共 58 个学习模块：

- 线性表：顺序表、单链表、双链表、循环链表、静态链表
- 栈和队列：顺序栈、链栈、顺序队列、链队列、循环队列、括号匹配、表达式计算、双端队列、层次遍历
- 数组与矩阵：数组地址映射、对称矩阵、三角矩阵、三对角矩阵、稀疏矩阵
- 串：朴素模式匹配、KMP
- 树：二叉树、BST、哈夫曼树、线索二叉树、AVL
- 图：邻接矩阵、邻接表、BFS、DFS、Prim、Kruskal、Dijkstra、Floyd、Bellman–Ford、拓扑排序、关键路径
- 查找：顺序查找、折半查找、红黑树、B 树、哈希表
- 排序：插入、折半插入、希尔、冒泡、快速、选择、堆、归并、基数排序

## 运行

### 方式一：直接打开

双击 `index.html`。项目不依赖第三方库，也不使用 ES Module。

### 方式二：本地服务器

在项目目录运行：

```bash
npm start
```

或：

```bash
python3 -m http.server 5173
```

然后打开 `http://localhost:5173`。

## 动画帧和代码映射

动画轨迹由 `algorithms.js` 生成：

```js
{
  visual: { type: 'array', values: [1, 2, 3], active: [1] },
  message: '比较当前元素',
  line: 2,
  vars: { i: 1 }
}
```

其中 `line` 是语言无关的语义步骤编号。`code-library.js` 将该编号映射到 C/C++、Java 和 Python 中不同的真实代码行，因此三种语言可以共享同一套动画轨迹。

新增算法时：

1. 在 `modules.js` 添加模块。
2. 在 `algorithms.js` 添加轨迹生成函数。
3. 在 `buildTrace()` 中注册 `demo` 标识。
4. 在 `code-library.js` 添加三种语言代码及语义步骤标记。
5. 复用现有 `visual.type`，或在 `app.js` 增加新的渲染器。

## v3 操作补全

每个数据结构模块新增结构操作标签页，并保持动画、变量框、逐步注释与三语言代码高亮同步：

- 顺序表：创建、插入、删除、访问、修改、查找、遍历
- 链表：创建、插入、删除、访问、查找、遍历、反转
- 栈：创建、入栈、出栈、访问栈顶、遍历、清空
- 队列/双端队列：创建、两端插入删除、访问、遍历、清空
- 矩阵：创建、访问、修改、遍历、压缩存储
- 树：创建、插入、删除、查找、先序、中序、后序、层序
- 图：创建、添加顶点、添加边、删除边、访问邻接点、BFS、DFS、原算法演示
- 哈希表：创建、插入、删除、查找、遍历
- 排序与查找模块：数据创建、算法运行、访问和遍历

操作选择会按模块保存在浏览器本地，下次进入该模块会恢复上次选择。
